Code Highlighter is a productivity and developer-focused Google Docs Add-on that automatically parses, themes, and syntax-highlights plain text code blocks directly within a Google Document.It bridges the gap between text editors and rich-text document writing.

Key Features
Multi-Language Support: Automatically parses and highlights snippets for major programming languages including C++, Python, and JavaScript.

Rich Theme Selection: Offers a wide selection of built-in syntax themes ranging from classic light/dark themes (GitHub, One Dark, Dracula, Monokai) to creative styles (Cyberpunk 2077, Matrix Hacker, Midnight Purple).

Deep Text Customization: Gives users granular control over font families (Consolas, Fira Code, Roboto Mono, etc.), point sizes, and formatting overrides (Force Bold or Force Italic).

Clean Native Integration: Runs in a responsive sidebar interface within Google Docs, preserving clean line structures, paragraphs, and list formats.
